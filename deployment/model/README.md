## 真实业务分析范围（用户已确认，首轮仅候选联调）

- 仅调用用户已有DeepSeek官方API，按实际token扣账号余额。
- 必要输入：WhatsApp/授权收件箱及已发送中的客户采购沟通、识别本次客户/采购所需电话/邮箱身份、必要已有CRM事实、相关报价图片；同一客户同笔采购的必要上下文及R01-R11规则。
- 不发送密钥、邮箱授权码、服务配置、整个数据库或与本次业务无关的邮件/聊天。系统通知和明显营销邮件先本地筛除，未知是否业务的内容按明确范围处理，不能把全265封直接称为全部有效客户询盘。
- 图片采用base64私密请求，不创建公开图片链接；保存本地来源/版本及识别失败状态。图片识别明确启用且来源校验后再接入。
- 第一轮真实联调只提取事实/候选与具体疑问，不直接修改客户或订单；通过正反例、对象归属及字段检查后按既有授权接通自动写入。模型不持有Twenty凭据，确定性工作流/统计保留唯一执行者。
- 实时目标保留，以新证据增量触发短批次及持久去重队列；同一分析任务含首次最多3次，失败不重置次数，无消息不调用模型。实际延迟及费用以联调验收报告为准。
