# 报价图片接入进度

2026-10-12 续接：用户明确报价主要在阿里发送，WhatsApp/邮箱偶尔发送。阿里聊天仍按原决定暂不接入，不从当前 WhatsApp/邮件记录推测阿里发送事实。

## 已完成并验证

scripts/quote_media.py 是只读邮件图片证据读取器。只为唯一且已核实身份的出站客户邮件建立图片引用；多个收件人、有抄送、未核实身份、系统邮件不自动归属。读取沿用已授权邮件账号和历史库，用 EXAMINE/readonly 与 BODY.PEEK，核实 UIDVALIDITY、原始头部和 BODYSTRUCTURE。附件文件名不用于决定本地文件路径。

资料保存在受现有私密 ACL 保护的 records/chat-signal/quote-media/：media.sqlite3 保留每次发送的客户、原邮件键、原版本、正文部分编号及邮件原始时间；图片按 SHA256 存储。两个发送记录对应相同内容时保留两个引用、复用一个二进制文件。未知时间保留空值，不用读取时间代替。

实际读取 Diana 三个发送引用、两个唯一图片。逐图本地检查：IMG_4832.JPG 是微信二维码；两次 IMG_4887.PNG 是同一张公司名片。均标记 excluded_nonquote，并保存内容散列和检查依据；没有传到外部模型，也不启动报价提醒。名为 PNG 的附件实际是 JPEG，按真实支持格式保存并记录 declared_mime_matches=false，不相信扩展名。

当前已核实 WhatsApp 客户有一张入站图片，没有出站报价图片。本轮未下载这张与出站报价无关的入站图片，也未实施 Evolution 媒体下载适配器。

scripts/quotation_facts.py 校验已提取的报价事实：美元口径、完整十进制、数量、单价×数量、小计与商品合计；冲突抛出需确认，不自动改数字。商品金额和运费分开，未知运费不填零、不生成含运费总价；报价不证明付款或发货。发送证据门槛包括已核实客户、实际出站发送、时间、对应采购和非历史回放，示例或草稿不启动计时。

复用先前获授权并保存的 Jumper T14 报价识别结果，数量1、单价/商品合计93.36USD校验通过；运费未知，总价未知，未绑定任何客户或订单。没有为同一示例再次调用模型。

12项图片读取回归 + 9项报价事实回归通过。实际邮件图片重复下载命中本地缓存，无新引用；截图、模型或CRM写入并未伪装成实际报价事件。
