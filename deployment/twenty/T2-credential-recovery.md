## 到期前续期或故障恢复

1. 在本地 Twenty 设置 → MCP 和 API → 接口中创建同角色、同范围的替代密钥。不要选择默认 Admin。
2. 在设置 → 应用 → 已安装 → Custom → 变量更新 T2后台提醒密钥；保存后不可回读完整值。
3. 覆盖项目私密副本并核验 ACL；不得输出密钥。已有副本只用于授权的同一服务恢复。
4. 手动扫描并验证一次真实状态事件及一次定时运行；均成功后，将旧 key 停用/撤销，保留配置记录。
