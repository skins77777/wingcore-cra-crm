# 自己启动 CRA

正常使用：电脑开机，登录当前 Windows 用户，等待约 1～3 分钟，打开 http://localhost:3000/home。CRM、WhatsApp 服务、审核后台、邮件采集和既有后台任务均已配置该用户登录后的自动启动。无需打开终端，也无需打开 Codex 才能让后台运行。

手动恢复：双击桌面“CRA 启动并打开CRM”。它静默触发现有的本地服务、审核后台和订单报表计划任务，检查本地服务，准备好后打开 CRM。服务已运行时可重复使用，任务调度器会避免同一任务并发执行。如果三分钟内仍未就绪，会显示启动检查结果，交给 Codex 排查即可。

此入口保存于 scripts/open-local-crm.py，状态为 runtime/desktop-start-status.json。桌面快捷方式只指向本项目脚本，未保存任何密钥。

当前为登录后启动；停留在 Windows 登录界面不会启动这些用户任务。锁屏后可以继续运行；电脑休眠或关机会停止处理。需要整天持续采集时保持电脑开机、不进入休眠。

本次已核实登录触发器和真实分钟恢复触发，并测试桌面入口。再次整机重启后的验收尚未进行。WSL 网络地址变化及受限代理维护参见 reboot-recovery-2026-10-12.md。
