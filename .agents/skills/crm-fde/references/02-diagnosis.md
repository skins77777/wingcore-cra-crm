# 简短开场与最少业务背景

## 本环节只做一件事

了解足够选择管理指标的产品/服务和客户类型，然后进入客户分级。完整销售流程访谈属于商机模块，不能因为“诊断”二字在开场展开全部业务问卷。

已有背景直接沿用。未知时可说：

> 我们会一步步确定客户怎么分级、每笔生意怎样推进、什么时候提醒，再把它们建进 CRM。你主要卖什么，客户主要是哪类人或企业？

不要在这句后接“从咨询到结束经过什么步骤”。不做长篇价值宣讲，不要求公司名、技术版本、账号权限等才能开始。

## 得到背景后的下一步

例如客户说“鲜切花，卖给周边国家花店、批发商，咨询、报价、成交”：保存产品、客户类型；后三项留作以后流程素材，然后进入 [客户分级](04-grading.md)：

> 我们先给客户建立五星等级，方便分配经营精力。先看采购潜力：你平时用支、扎还是箱衡量采购量？

知道单位后问普通客户一个月大约采购多少；也可把单位、周期和普通量级合成一个简短问题。给五档建议，不能直接套用别家公司的 500 件。

低频项目型业务改用单次或年度金额，并说明统一周期的作用。客户已明确分级规则则记录并跳过已定部分。

## 哪些信息留到对应环节

| 信息 | 合适的位置 |
|---|---|
| 数量单位、周期、普通客户量级 | 分级 |
| 独立采购与同单修改、完整销售步骤 | 商机概念与完整流程 |
| 到账和单据来源 | 采用阶段的细化；首版人工核实 |
| 人员及任务分配 | 负责人 |
| 已有 CRM、资料、平台能力 | 已知时先记录，实施前自行盘点 |
| WhatsApp/财务产品 | 业务背景或扩展记录，不开启接入访谈 |

客户主动提出当前痛点或要求先做某部分，可以按其要求进入，记录跳转和返回点。仅仅提到“报价、成交”不表示要求跳过分级。

## 本环节的完成与记录

产品/服务、客户类型足以决定下一问时就完成 B0；不要求业务画像表每个格子都填完。首次有效回答后在可写客户项目建立/更新档案，方法见 [记录与续接](11-blueprint.md)。下一步记录为 G1 或已明确的客户选择。

诊断贯穿建设：发现同客户多笔采购、输单原因无法统计等问题时，在对应模块解释影响、提出方案，不在开场集中问完。全貌访谈及流程模板统一在 [商机教材](05-process.md)，避免两份入口引出不同顺序。
